# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of our services and software seriously. If you believe you have discovered a vulnerability, please report it responsibly so we can remediate it before public release.

### How to Submit a Report

**Do NOT open a public GitHub issue, pull request, or discussion.**

To report an issue privately:
1. **GitHub Security Advisory (Preferred):** Navigate to the repository's **Security** tab, select **Advisories**, and click **New draft security advisory** (or click **Report a vulnerability**).
2. **Email:** If you are unable to use GitHub Advisories, send an encrypted message to `security@proofstreamapp.com`.

### What to Include

Please provide as much information as possible to help us reproduce and address the issue quickly:
- Description and potential impact of the vulnerability.
- Affected components, API routes, contracts, or commit hashes.
- Step-by-step reproduction instructions or a minimal proof-of-concept (PoC).
- Any proposed remediations or patches.

### Scope

- **In Scope:** Application code in this repository, smart contract integration logic, client authentication flows, and associated APIs.
- **Out of Scope:** Volumetric/DDoS attacks, physical security attacks, social engineering/phishing of team members, and reports from automated scanners without verifiable exploit impact.

### Response Timelines

- **Initial Acknowledgment:** Within 48 hours of report submission.
- **Triage & Assessment:** Within 5 business days, confirming validity and severity.
- **Remediation & Patching:** Timeline depends on severity, targeted within 30 to 90 days. We will keep you informed of our progress.

### Safe Harbor

If you make a good-faith effort to comply with this policy, avoid disrupting production services, do not access or destroy private user data, and allow reasonable time for remediation before public disclosure, we consider your research authorized and will not pursue legal action.
